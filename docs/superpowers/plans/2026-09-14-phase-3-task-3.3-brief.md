## Exit checks

Every delivered instruction, reference and upstream byte is verified and bound
into the record; a missing or changed predecessor or ancestor fails before call
or acceptance; over-ceiling context refuses typed with no truncation; upstream
text and citation register never satisfy a citation; Blocked/refused attempts
never reach a consumer; disclosed conflicts and mandatory registers pass
unchanged; no source or model text selects code, paths or tools.
