## Contract and scope

1. Migration `<ordinal>_reservation_price.sql` — the ordinal is allocated by
   the coordinator at integration (the tree is at `0021`; the remediation
   stream holds `0022` and `0023`):
   `ALTER TABLE budget_reservations ADD COLUMN price_model text NOT NULL,
   ADD COLUMN price_input numeric NOT NULL, ADD COLUMN price_output numeric
   NOT NULL, ADD COLUMN price_as_of date NOT NULL` — with defaults only for
   the migration of existing rows (`'legacy'`, `0`, `0`, `1970-01-01`) and a
   CHECK that new rows carry a real model name; existing rows keep their
   amounts.
2. `pricing.priced_request(price, request_bytes: int) -> Decimal` =
   `input × request_bytes + output × MAX_COMPLETION_TOKENS`, exact context,
   refused if `request_bytes > MAX_REQUEST_BYTES`.
3. `reserve(conn, attempt_id, amount, *, price: ModelPrice, lease)` writes the
   four columns; `reserved_for` returns amount and price.
4. `runtime._run_node`: the attempt unit measures `len(provider.request_bytes(
   prompt, json_object=True))` for the prompt it just built and reserves
   `priced_request(execution.price, measured)`; `worst_case` stays as the
   run-ceiling admission check (`run_route` still refuses a ceiling below one
   worst case before an attempt exists), so invariant 8's "no provider call
   without a reservation" and "refuse before overspend" both hold with a
   smaller reservation. The replay path (`replay_billed`) reserves nothing
   new, as today.
5. `scripts/qualify.py` prints the price it will reserve under, beside the
   database and blob root it already prints.
