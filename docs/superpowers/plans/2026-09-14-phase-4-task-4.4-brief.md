## Decisions

1. **Stream endpoint:** `GET /api/v1/cases/{case_id}/events?run=`.
   - READER standing on the case is required.
   - An unknown or unauthorised case gets the private 404 `CASE_NOT_FOUND`. A run
     from another case gets `RUN_NOT_FOUND`.
   - It carries the case's audit actions, plus `run_events` for the named run.
   - It is case-scoped because withdrawal is recorded in `audit_events`, not
     `run_events`, and one stream means one held connection per tab.
   - `/api/runs/{run_id}/events` is removed and its tests move.
   - Directory has no stream.
2. **Event names:** a closed, lower-case `EventName` in `server/api/wire.py`,
   carried in the committed schema. The mapping lives in `server/api/events.py`.
   Each name only tells the client which sections to refetch.

   | Name | Sources | Refetches |
   |---|---|---|
   | `run_progress` | `ROUTE_PINNED`, `INPUT_PINNED`, `ATTEMPT_STARTED`, `CALL_OUTCOME_RECORDED` | Run |
   | `handoff_accepted` | `ATTEMPT_ACCEPTED` | Run, Analysis |
   | `run_terminal` | `RUN_COMPLETE`, `RUN_FAILED`, `RUN_BLOCKED`, `RUN_CANCELLED` | Run, Analysis |
   | `sources_changed` | audit `SOURCE_WITHDRAWN`, plus 4.2's admission actions | Upload, Run, Analysis |
   | `runs_changed` | 4.2's run-created, input, gate, start, retry and cancel actions | Run, Analysis |

   - Actions for disabled sections are declared silent.
   - A test requires every `RunEvent` and audit action to map to a name or be
     declared silent.
   - `authority_changed` is removed: the client derives staleness itself
     (decision 6).
   - Revocation has no event; the standing recheck closes the stream.
3. **Frames and resume.**
   - Each frame is `id: {audit_seq}.{run_seq}`, `event: {name}`, `data: {}`.
   - On connect the server first sends a cursor-only frame, `id: {heads}` (SSE
     sets `lastEventId` from it and dispatches nothing).
   - `Last-Event-ID` must match `^(0|[1-9][0-9]{0,15})\.(0|[1-9][0-9]{0,15})$`,
     checked as ASCII. A marker that is missing, malformed, oversized or ahead of
     the current heads resumes from the heads.
   - Delivery starts strictly after the marker.
   - On every reconnect `open`, the browser refetches the visible documents.
4. **Lifetime.**
   - Standing is rechecked before each frame and on each idle poll. When it is
     lost, the stream closes; the reconnect gets 404, `EventSource` stops, and
     the region becomes `unavailable`.
   - `TAIL_DEADLINE` stays at 300 s, after which the browser reconnects with its
     marker.
   - Once the run's terminal event has been delivered (or the marker is past it),
     the stream never reads `run_events` again. Only the audit poll continues.
     This fixes F16.
   - Polling continues at `POLL_INTERVAL`. The ledger's cost figure is updated.
5. **Refetch and late responses.**
   - Each section has at most one fetch in flight. A name that arrives mid-flight
     marks the section dirty, and exactly one more fetch follows.
   - A case or run change closes the tail, aborts the in-flight fetch, and bumps
     the `authority.ts` sequence. A response under an old ticket is discarded.
   - The Workspace key is `section|case|run`.
6. **Stale view, Reload and local state.**
   - Analytical identity:
     - Run: the displayed `run.run_id`.
     - Analysis: `displayed_run_id` plus the sorted `record_sha256`s.
     - Directory and Upload have none and always refresh.
   - A refetch with the same identity replaces the document.
   - A refetch with a different identity becomes `pending`. The region shows
     `stale` over the current document until the user reloads.
   - Withdrawal still applies to a stale view, through
     `withWithdrawals(displayed, withdrawalsOf(latest))`. A 404 makes the view
     `unavailable` at once.
   - The view mount key is `${case}|${displayedRunId}` (R5).
   - A section error boundary renders `RENDER_FAILED` (R4).
7. **Evidence page endpoint:**
   `GET /api/v1/cases/{case_id}/runs/{run_id}/sources/{source_id}/pages/{page}`.
   - Identity is checked first, then READER standing.
   - The run must belong to the case.
   - The source must be a live member of the run's pinned source-set version, with
     document, extractor identity and output digests matching (the
     `_RUN_BLOCK_QUERY` join).
   - Anything unavailable, including pages outside 1–500, is the same 404
     `EVIDENCE_NOT_AVAILABLE` with no text. Add it to `_STATUS`.
   - Responses are `cache-control: no-store`.
   - The response is a text layer: `source_tokens` grouped by `(region_id,
     line_id)` into lines (joined text plus union rectangle, in stored
     coordinates).
   - At most 2,000 lines, else `partial` with `LIST_TRUNCATED`.
   - No renderer: pdfium, MuPDF or poppler would add a native untrusted-PDF
     parser on a request path, with a CVE stream and licensing to manage. The
     text layer is the coordinate space citations were anchored in.
   - The drawer labels it "Text layer from the token index".
   - `IO_BUDGET = 2`, plus one digest-verified blob read.
8. **Page frame and highlight geometry.** The frame comes from the pinned blob,
   according to the stored extractor identity:

   | Stored identity | Frame |
   |---|---|
   | `caos.pdfminer` v2 | `(0, 0, crop_w, crop_h)`, y down |
   | `caos.pdfminer` v1 | `_crop_frame(page)` in layout space, y up (§44.4) |
   | `caos.plain-text` | from its stored configuration, y down |
   | other | `SOURCE_IDENTITY_INVALID` (503) |

   - PDF frames come from a new frame operation in the §47 child. It reads page
     boxes and `/Rotate` only, under the same deadline and decoded-byte budget.
   - The frame is sent as `FrameView{x0, y0, x1, y1, y_axis}`.
   - One pure browser function, `toFraction(rect, frame)`, places both the text
     lines and the citation rectangles.
   - A rectangle not wholly inside the frame is not drawn, and the drawer notes it.
9. **Drawer bound to the visible snapshot.**
   - `EvidenceProvider` is keyed by `section|case|displayedRunId` (R1).
   - The open state holds a citation identity, `(record_sha256, source_id, page,
     index)`, plus the element that opened it.
   - Each render re-resolves that identity against `useVisibleSnapshot()`:
     - If the source is withdrawn, the drawer shows the withdrawal and drops the
       page layer (R2).
     - If the citation is gone, the drawer closes. Focus returns to the section
       heading when the opener has left the page.
   - A stale view keeps the drawer on the snapshot being shown.
10. **Report, Committee and Book.** Port R6 and R7 and fix them now in the
    dormant components, with unit tests on those components. They are Phase 4
    exit checks, the fixes are small and local, and deferring them would ship a
    known defect into a later enablement. Browser proof waits until those
    sections are enabled (recorded limit).
11. **Real-API proof.**
    - Backend: real ASGI HTTP streaming against PostgreSQL.
    - Browser: vitest with fake `EventSource` and `fetch`, plus workbench specs
      over the v1 demo middleware.
    - 4.5 re-runs these titles in the real-stack journey.
