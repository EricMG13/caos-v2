## Scope

1. Per-document extractor dispatch from bytes inside `admit_pack` (never the
   filename).
2. Correct PDF word splitting; one declared coordinate convention across page
   rotation and crop; versioned extractor identity (v2).
3. Typed limits on documents, bytes, pages, tokens and time before expensive work.
4. Atomic packs, mixed ones included; no document text in any refusal or log.
5. Citations anchor only within the exact blocks delivered to a node.

**Non-scope:** quote-supports-claim checks, fact/calculation/judgment read model
and decimal limits (3.3/3.4); sub-source delivery selection; OCR, passwords,
bounded line groups, quote normalisation, blob sweep, streaming blob reads,
browser rectangle normalisation (4.4).

## Current gaps (at `f8190e9`)

- One extractor per pack, default plain text (`server/evidence/ingest.py:86,98`);
  the harness passes none, so PDFs are read as text.
- Extraction outside any guard (`ingest.py:112`); pdfminer encryption and
  internal errors can escape raw (`pdf.py:83`).
- `_runs` drops `LTAnno` word breaks (`pdf.py:111-131`): positioned words merge.
- Identity v1 records `laparams: "default"` only; PDF bottom-left vs plain-text
  top-left conventions undeclared; CropBox ignored.
- No byte/page/token/document/time ceiling; all pages held in memory.
- `verify_citations(delivered: set[UUID])` checks sources only.

## Exit checks

The three Phase 3 exit checks pass through the named REDs, each observed failing
first. A refused pack leaves no source, token, block or extraction rows; no
refusal, chain or log carries document text. New admissions record identity v2;
v1 rows still verify. No path sends a PDF through plain text. No source-only
`verify_citations` remains. §44 recorded; `CLAUDE.md` ledger updated.

The undelivered-pages exit is enforced by the anchoring rule at
`verify_citations`, which is where its three named tests prove it. In
production a run delivers every block of every pinned source, so nothing yet
narrows delivery below a whole source; the executor-level
`test_a_quote_outside_the_captured_blocks_refuses_the_handoff` narrows it only
by deleting a block with the immutability trigger disabled and is wiring
evidence, not exit evidence. `CLAUDE.md`'s Repair Phase 3 ledger records the
gap until per-node evidence selection exists.
