## Findings at base that bind this task

1. **A direct listener allows total impersonation.**
   - The image runs uvicorn on `0.0.0.0`, and `actor_from_headers` believes any well-formed `x-caos-user` and `x-forwarded-groups`.
   - Nothing proves that a request passed through the edge.
2. **The trust switch is ambient.** `.env.example` sets `CAOS_TRUST_ROLE_HEADER=1` and the Makefile exports it, and nothing checks it at boot.
3. **Repeated or lookalike identity headers can win.**
   - Starlette's `Headers.get` returns the first instance, so an edge that appends rather than replaces lets the client's copy through.
   - A hop that normalises `_` to `-` lets a lookalike such as `x_caos_user` through.
4. **The real dev UI sends no identity.** The Vite proxy forwards no subject, so `make dev-ui` against the real API gets 401.
5. **The dev API is open to DNS rebinding.** The loopback API accepts any `Host`.
6. **The image carries no frontend.** `.dockerignore` whitelists only `requirements.txt`, `server/` and `vendor/`.
7. **Mounting static at `/` inside FastAPI breaks API refusals.**
   - It shadows 405 `ENDPOINT_NOT_FOUND` on `/api/*`.
   - `/docs`, `/redoc` and `/openapi.json` are also served, and Swagger loads a script from a CDN.
8. **uvicorn trusts forwarded headers by default,** so a loopback check needs the real socket peer and `--no-proxy-headers`.
9. **`GET /api/health` is not served.**
10. **The deterministic provider exists only under `tests/`.**
    - `server/provider.py` speaks HTTPS only.
    - The seam for injecting a provider is `run_worker(execution_for=…)`.
11. **CAOS issues no cookie.** SameSite is the edge's contract; the backend adds an Origin check.

## Decisions

1. **Topology: FastAPI serves the static export; no proxy inside the image.**
   - The Dockerfile builds in two stages:
     - build: `node:24-slim`, pinned by digest, runs `npm ci --ignore-scripts && npm run build`;
     - runtime: the existing Python image, with `COPY --from` of `dist` to `/app/site`.
   - The image runs as two containers:
     - `api`: `python -m uvicorn server.api.site:application --host 0.0.0.0 --port 8000 --workers 1 --no-proxy-headers --no-server-header --limit-concurrency 32`
     - `worker`: `python -m server.engine.worker`
   - No supervisor.
   - Why:
     - nginx or Caddy would add packages to scan and a supervisor to run.
     - The edge is operator infrastructure anyway.
     - `--limit-concurrency` bounds unpooled connections (§11).
     - The Node stage is not in the final image.
2. **The edge contract (recorded in §53 and in the `server/api/edge.py` docstring).**
   - The operator's edge authenticates with OIDC and forwards only to a private API listener.
   - It strips these inbound headers: `x-caos-user`, `x-forwarded-groups`, `x-caos-role`, `x-caos-edge-token`, every header whose name contains `_`, and its own session cookie.
   - It sets exactly one of each: `x-caos-user` (a UUID), `x-forwarded-groups` and `x-caos-edge-token`.
   - It passes these through: `origin`, `sec-fetch-*`, `idempotency-key`, `last-event-id`, `content-type` and `content-length`.
   - Session cookie: `__Host-` prefix, `Secure; HttpOnly; SameSite=Lax`. Lax rather than Strict, because Strict breaks the OIDC return.
   - SSE must be unbuffered, with an idle timeout above 300 s.
3. **The edge proves itself with a shared token (stdlib `hmac`, no dependency).**
   - Edge mode means `CAOS_EDGE_TOKEN` is set.
     - Boot refuses `EDGE_CONFIG_INVALID` if the token is under 32 bytes, if `CAOS_PUBLIC_ORIGIN` is missing or malformed, or if `CAOS_TRUST_ROLE_HEADER` is set at all.
     - Every request except `GET|HEAD /api/health` needs the token (`hmac.compare_digest`). Otherwise the answer is 403 `EDGE_NOT_TRUSTED`, before routing, identity or body.
     - The guard deletes the token header from the scope, so the app never sees it.
   - Dev mode means no token.
     - The guard serves only when both the socket server and the client are loopback addresses and the `Host` is `localhost`, `127.0.0.1` or `[::1]`.
     - Anything else gets 403 `EDGE_NOT_TRUSTED`, except health. An image started without a token therefore answers health and nothing else.
   - `identity.py` believes the role header only when the switch is `1` and no edge token is set.
   - Rejected alternatives:
     - A unix socket or a loopback-only bind: breaks probes and the local proof.
     - mTLS: needs certificates.
     - JWT verification: needs a dependency.
   - Residual risks:
     - The backend cannot detect an edge that fails to strip client headers; the test edge and §53 pin the contract.
     - Rotating the token needs a restart.
4. **Header hygiene, in both modes.**
   - More than one instance of `x-caos-user`, `x-forwarded-groups` or `x-caos-role` gets 401 `NOT_AUTHENTICATED`.
   - So does a lookalike: a name that differs from one of those only by `_` versus `-`, or by case.
5. **Origin and `Sec-Fetch-Site`, the second half of the CSRF split.** These apply to `/api` and `/api/*`, except health.
   - `sec-fetch-site: cross-site` or `same-site` gets 403 `ORIGIN_REFUSED`.
   - Unsafe methods need either `sec-fetch-site: same-origin`, or no `sec-fetch-site` plus an `origin` equal to the allowed origin. An `origin` that differs is refused; a request with neither header is refused.
   - `none` is allowed for GET only.
   - The allowed origin:
     - edge mode: `CAOS_PUBLIC_ORIGIN`;
     - dev mode: `http://{localhost,127.0.0.1,[::1]}:{5173,8000}`.
   - No CORS middleware, and no response sets a cookie.
6. **Security headers and CSP on every response.**
   - CSP: `default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self'; font-src 'self'; connect-src 'self'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'; object-src 'none'; require-trusted-types-for 'script'; trusted-types 'none'`
   - Other headers: `nosniff`, `referrer-policy: no-referrer`, COOP and CORP `same-origin`.
   - Cache control:
     - `/api/*`: `no-store`;
     - `/assets/*`: immutable, one year;
     - HTML: `no-cache`.
   - `FastAPI(docs_url=None, redoc_url=None, openapi_url=None)`.
   - A directive is widened only for a named violation, recorded in §53.
7. **Static deep links via `server/api/site.py`.**
   - `application = EdgeGuard(dispatch)`.
   - `/api` and `/api/*` go to `server.api.app:app`, lifespan included.
   - Everything else is GET/HEAD-only `StaticFiles(CAOS_SITE_ROOT, html=True, follow_symlink=False)`. Other methods on site paths get 405 with no body.
   - `/directory/`, `/upload/?case=`, `/run/?case=&run=` and `/analysis/?case=&run=` serve the exported `index.html`.
   - With `CAOS_SITE_ROOT` unset, non-API paths are 404. If it is set but contains no `index.html`, boot refuses.
   - `server.api.app:app` also installs `EdgeGuard`.
8. **`GET /api/health`.**
   - Response: a closed `HealthDocument{status, store, bundle, blobs, checked_at}`. No auth or token needed. 200 only when all three probes are OK and fresh; otherwise 503.
   - One lifespan task runs the three probes every 10 s.
     - Each probe runs in `asyncio.to_thread` under a 2 s timeout, single-flight.
     - A result older than 30 s reads `PROBE_STALE`; before the first run, `PROBE_NOT_RUN`.
   - The probes:

     | Probe | What it checks |
     |---|---|
     | store | `connect(url, connect_timeout=2)`, `SET LOCAL statement_timeout='2s'`, then a read-only `verify_schema(conn)` factored out of `_migrate` (no DDL, no advisory lock) |
     | bundle | a fresh `Bundle(VENDORED_BUNDLE)` whose manifest equals the process bundle's, else `BUNDLE_MOVED` |
     | blobs | the root is configured, is a directory, and has `R_OK\|W_OK\|X_OK`; nothing is written |

   - The request path does no I/O (`IO_BUDGET = 0`).
9. **Dev identity, in the Vite proxy only.**
   - The proxy removes client `x-caos-*` and `x-forwarded-*` headers and any header name containing `_`.
   - It then sets `x-caos-user` from `CAOS_DEV_USER` and `x-caos-role` from `CAOS_DEV_ROLE` (default `ANALYST`).
   - If `CAOS_DEV_USER` is unset, it injects nothing and the API answers 401.
   - The production dist scan forbids the dev user value and `x-caos-`.
   - `make dev-api` serves `server.api.site:application` on 127.0.0.1 with `--no-proxy-headers`.
10. **The deterministic journey provider.**
    - `tests/journey/worker.py` calls `run_worker(config, execution_for=…, stopping=…)` with `RealisticLiteCompletions(source_id)` and a fixed, dated price.
    - It runs from the same image, with `./tests` mounted read-only, `PYTHONPATH=/opt/caos-tests:/app`, and the same uid and blob volume. It is in the Compose `journey` profile only.
    - `tests/` is never in the image, and `server/` has no provider selector. Tests assert both, and assert that the image worker exits 2 `PROVIDER_NOT_CONFIGURED` when no provider is configured.
    - No credentials are in the environment.
11. **Smoke stack: `compose.smoke.yaml`, project `caos-workbench-smoke`, disposable.**
    - `smoke-postgres`: pinned digest, tmpfs, no host port.
    - `api`: a per-run `CAOS_EDGE_TOKEN`, `CAOS_PUBLIC_ORIGIN=http://127.0.0.1:18080`, published on `127.0.0.1:18000:8000`, with the `smoke-blobs` volume.
    - `worker` runs under profile `smoke`; `journey-worker` under profile `journey`.
    - The test edge, `tests/journey/edge.py`, runs on the host on 127.0.0.1:18080 using the locked uvicorn and httpx.
      - It implements decision 2.
      - `GET /_edge/login?persona=analyst|intruder` sets an HttpOnly, SameSite=Lax session cookie. Over http-localhost it drops `Secure` and the `__Host-` prefix; this is recorded.
    - `make smoke-production`:
      1. builds the image;
      2. runs `pytest -m production_image tests/test_production_image.py`;
      3. runs `tests/journey/run.py`, which brings the stack up, starts the edge and journey worker, runs Playwright, then `down -v`.
    - `make smoke-production` becomes the last step of `make check`. `production_image` is deselected from `make test`, and `CAOS_REQUIRE_IMAGE=1` turns skips into failures.
12. **Worker kill and restart on the real stack.**
    - 4.3 owns the per-boundary crash proofs.
    - The journey adds one real-stack check: `JOURNEY_EXIT_AFTER_FIRST_ACCEPT=1` makes the worker `os._exit(137)` once, after its first acceptance, and the spec restarts the container.
    - The same pause proves the stale-view hold until Reload.
