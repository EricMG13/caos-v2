## Contract and scope

1. **Projection.** `Projections.blockers: tuple[tuple[str, str], ...]` —
   `(module_id, why_now_or_blocker)` for every T8 row whose readiness is
   `CONDITIONAL` or `BLOCKED`, each cell passed through `BoundaryText.of`
   with a 512-character bound and refused `HANDOFF_MALFORMED` past it; the
   record format does not change (projections are re-derived from the
   Markdown, not stored). `PROJECTION_FIELDS` gains `blockers` so a
   qualification key can assert on it.
2. **Wire.** `NodeView.gate_reason: Bounded512 | null` — the blocker text
   for a node whose `gate_verdict` is CONDITIONAL or BLOCKED, null otherwise;
   `RunView.supersedes: UUID | null` and `RunView.superseded_by: UUID |
   null`; `CreateRun.supersedes: UUID | null = None`. Pinned key sets, the
   TypeScript mirror, `schema.json` and every fixture carrying a run body
   move together; the seven fixtures carry `null`.
3. **Store.** Migration `<ordinal>_supersedes.sql` (ordinal allocated at
   integration): `ALTER TABLE runs ADD COLUMN supersedes_run_id uuid NULL
   REFERENCES runs (run_id)`; a trigger refusing UPDATE of the column once
   non-null; `CREATE UNIQUE INDEX runs_one_successor ON runs
   (supersedes_run_id) WHERE supersedes_run_id IS NOT NULL`. `start_run`
   gains `supersedes: UUID | None`; inside the unit it selects the target
   `FOR SHARE`, refuses `RUN_NOT_FOUND` for another case (private 404
   equivalence: the same code as an unknown run) and `RUN_NOT_BLOCKED` for
   any status but BLOCKED, then inserts.
4. **Command.** `create_run` passes `body.supersedes` through; the audit
   payload binds it; `RunCreated` unchanged.
5. **Read.** `reads/run.py` reads the column both ways (`BLOCKED_BY_IO`
   pattern; `IO_BUDGET` +1, measured); the Run section shows "supersedes run
   …" / "superseded by run …" in the run panel and the gate reason in the
   node detail. The Run section's create-run control offers `supersedes`
   pre-filled when the displayed run is BLOCKED and the case's current
   source-set version is newer than the run's pinned version.
6. **Decision.** Before this lands, a dated `docs/DECISIONS.md` entry
   records (a) that resume is withdrawn in favour of the successor link, and
   (b) whether QA `Restricted` may release CP-6 as RESTRICTED. This task
   implements (a) only; (b) is decided, not built, here.
